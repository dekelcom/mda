# כרטיס כיס לחובש — PWA

אפליקציית כרטיסי כיס לרפואת חירום טרום־אשפוזית (מד״א), הניתנת **להתקנה** בטלפון
כאפליקציה עצמאית ועובדת **אופליין** לחלוטין.

## מה בפנים
```
index.html            אפליקציה מלאה (כל 20 צדי הכרטיסים מוטמעים) 
manifest.webmanifest  הגדרות ההתקנה (שם, אייקונים, מסך מלא)
sw.js                 Service Worker — שמירה במטמון לעבודה אופליין
icons/                אייקוני האפליקציה (192/512/180/32) + icon.svg למקור
```

## הרצה מקומית (לבדיקה)
Service Worker לא רץ מ־`file://`, צריך שרת:
```bash
cd pwa
python3 -m http.server 8080
# פתחו http://localhost:8080
```

## פרסום כדי שאפשר יהיה להתקין
צריך HTTPS. הכי מהיר:
- **Netlify Drop** — גררו את תיקיית `pwa` ל־https://app.netlify.com/drop
- **Vercel** — `npm i -g vercel && vercel` בתוך התיקייה
- **GitHub Pages** — העלו את התוכן ל־repo והפעילו Pages

אחרי הפרסום, בטלפון:
- **Android/Chrome** — תפריט ⋮ → "התקן אפליקציה" / "הוסף למסך הבית"
- **iPhone/Safari** — שיתוף → "הוספה למסך הבית"

האפליקציה תיפתח כמו אפליקציה רגילה, במסך מלא, גם ללא רשת.

## החלפת הלוגו הרשמי
האייקונים ב־`icons/` הם זמניים. להחלפה בלוגו הרשמי של מד״א:
1. שימו קובץ מרובע (למשל `logo.png`, מומלץ 1024×1024).
2. צרו ממנו גרסאות בגדלים 192, 512, 180, 32 ושמרו ב־`icons/`
   באותם שמות קבצים.
3. אין צורך לשנות דבר נוסף — `manifest.webmanifest` כבר מצביע עליהם.
