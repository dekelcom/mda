# מד״א · תרגול מבחן תיאוריה (MDA Theory)

אפליקציית תרגול למבחן התיאוריה בנהיגה, מבוססת על **מאגר השאלות והתשובות הרשמי של משרד התחבורה**.
נבנתה עבור נהגי רכב חירום ואמבולנס במד״א, ומתאימה לכל לומד לקראת מבחן התיאוריה.

בנוי ב־**Next.js 15 (App Router) + React 19 + Tailwind CSS**, בעברית מלאה (RTL), מוכן לפריסה ב־Vercel.

## מה יש במאגר

- **1,802 שאלות** עם 4 אפשרויות ותשובה נכונה מסומנת
- **4 נושאים**: חוקי התנועה (901), תמרורים (391), בטיחות (400), הכרת הרכב (110)
- **599 שאלות עם תמונה** (תמרורים ותרחישי כביש)
- תיוג לפי **סיווג רישיון**: 1 / A / B / C1 / C / D

## תכונות

- **תרגול חופשי** – שאלות אקראיות עם משוב מיידי, סינון לפי נושא וסיווג רישיון, ומעקב אחר אחוז הצלחה.
- **מבחן מדומה** – 30 שאלות במתכונת המבחן הרשמי, עם ציון עובר וסקירת תשובות.
- **מאגר** – חיפוש חופשי בכל השאלות, גילוי תשובות לפי דרישה.
- **תמונות** – נטענות משרתי משרד התחבורה דרך שרת ביניים (`/api/img`) כדי לעקוף חסימת `http` בדף `https`.

## הרצה מקומית

```bash
npm install
npm run dev
# http://localhost:3000
```

בנייה לפרודקשן:

```bash
npm run build && npm start
```

## פריסה ל־Vercel

חברו את הריפו ל־Vercel — Next.js מזוהה אוטומטית, אין צורך בהגדרות מיוחדות
(**Root Directory** נשאר ברירת המחדל `/`).

השרת (Node runtime) נחוץ בגלל `/api/img`, לכן אין להשתמש בייצוא סטטי מלא (`output: "export"`).

## עדכון המאגר מקובץ ה־XML

קובץ המקור: `data/source.xml` (ה־RSS הרשמי של משרד התחבורה).

```bash
npm run parse   # data/source.xml -> data/questions.json (+ public/questions.json)
```

הסקריפט (`scripts/parse-xml.mjs`) מחלץ לכל שאלה: מזהה, נושא, טקסט, אפשרויות,
התשובה הנכונה, קישור לתמונה, וסיווגי הרישיון.

## מבנה

```
├── app/
│   ├── page.tsx            # דף הבית + סטטיסטיקות
│   ├── practice/           # תרגול חופשי
│   ├── exam/               # מבחן מדומה
│   ├── browse/             # מאגר + חיפוש
│   ├── about/              # אודות
│   └── api/img/route.ts    # שרת ביניים לתמונות
├── components/             # רכיבי UI (כרטיס שאלה, מסננים)
├── lib/                    # טיפוסים, טעינת נתונים, לוגיקת מבחן
├── data/                   # source.xml + questions.json
├── public/questions.json   # נטען בצד הלקוח
└── scripts/parse-xml.mjs   # מפענח ה-XML
```
